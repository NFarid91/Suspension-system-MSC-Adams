# Suspension System — MSC Adams

## Overview
A multibody dynamics simulation project developed in MSC Adams to study the motion and dynamic response of a vehicle suspension system.

## Objectives
- Build a representative suspension mechanism in MSC Adams.
- Simulate suspension motion under an applied excitation.
- Observe the dynamic behavior of the mechanism.
- Use multibody dynamics concepts to evaluate vehicle-system motion.

## Software
- MSC Adams
- Adams/View / Adams Car concepts

## Engineering Topics
- Multibody dynamics
- Vehicle suspension
- Kinematics and dynamics
- Joint and constraint modeling
- Motion excitation
- Dynamic response visualization

## Repository Contents
The repository currently contains a simulation video demonstrating the final suspension-system model and its dynamic behavior.

## Notes
For a more reproducible engineering study, the repository can be expanded with the Adams model files, model topology, joint definitions, force/motion inputs, simulation parameters, and quantitative plots.
